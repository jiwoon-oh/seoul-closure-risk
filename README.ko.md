# 서울 골목상권 외식업 순감소 분석 — H2와 보조질문 2

[English](README.md) · [원본 프로젝트 폴더](https://github.com/jiwoon-oh/ai-data-bootcamp/tree/main/project/h2_nb)

> 이 README는 팀 프로젝트 중 **H2(업종 간 순감소 격차와 규모 교란)**, **보조질문 2(다음 분기 순감소 관련 변수)**, 그리고 연결된 예측·운영 분석을 정리한 문서다. 자치구별 순감소 전환 업종을 찾는 핵심 질문과 H1은 다른 팀원 담당 범위이므로 포함하지 않았다.

## 1. 결과부터

서울 골목상권에서 한식음식점의 다음 분기 순감소 비율은 다른 외식업보다 높아 보였다. 그런데 점포 수와 입지 조건을 맞추고 나니 비교 결과가 반대로 나왔다. 더 자세히 보면 이 차이조차 **점포 규모에 따라 방향이 달랐다.**

| 확인한 내용 | 결과 | 해석할 때 주의할 점 |
|---|---|---|
| 단순 순감소율 | 한식 **25.3%**, 타 외식업 **22.9%** | 격차 +2.4%p |
| 1위 업종 선택의 영향 | 순열검정 **p = 0.344** | 1위를 고른 결과일 가능성을 무시할 수 없음 |
| 매칭 후 평균 격차 | **−5.57%p**, 95% CI **[−7.08, −4.17]** | 관측조건이 비슷하고 짝이 있는 표본에만 해당 |
| 다른 추정 방식 | 이중강건 **−6.00**, 반사실 **−6.01**, 대안라벨 **−8.71** (%p) | 방법을 바꿔도 평균 방향은 음수 |
| 매칭 쌍의 규모별 차이 | 가장 작은 구간 **−13.6%p** → 가장 큰 구간 **+1.8%p** (작은 3개 구간은 신뢰구간이 0을 포함하지 않고, 큰 2개 구간은 포함) | 단일 ATT만 보여주면 중요한 이질성이 가려짐 |
| 다음 분기 순감소 관련성 | `log_점포수` AME **+14.28%p**, `log_유동인구` **+0.72%p**(`p = 0.078`) | 순감소 지표 자체의 산술적 특성도 작용 |
| 순감소 예측 | 롤링 AUC **0.666 ± 0.011** | 아주 정확한 개별 예측 모델은 아님 |
| 폐업 건수 기반 운영 평가 | 상위 50칸 정밀도 **0.780**, 점포수 규칙 **0.380** | 전체 AUC의 작은 차이와 운영구간의 이점은 구별해야 함 |
| 2026년 2분기 산출물 | 골목상권 **2,737칸** 예측 | 실제 2026Q2 결과가 아니라 그 시점에 대한 예측치 |

**H2 판정은 '부분 지지(방향은 예상과 다름)'로 남겼다.** 애초 가설은 규모·유동인구를 맞추면 한식과 타 업종의 격차가 줄어든다는 것이었다. 실제로는 +2.4%p가 −5.57%p로 **역전**되었고 절댓값은 커졌다. 관측된 격차가 조건에 민감하다는 점은 확인했지만 가설의 방향까지 맞힌 것은 아니었다.

특히 **−5.57%p를 한식 업종 전체의 고정된 효과로 소개해서는 안 된다.** 점포 규모별로 나누면 표본 내 비교 결과가 큰 차이를 보인다. 또한 매칭은 임대료나 점주의 역량 같은 관찰되지 않은 조건을 제거하지 못하므로 인과효과로 단정하지 않는다.

## 2. 무엇이 문제였나

### 누구의 의사결정에 필요한 분석인가

- 자치구 소상공인 지원 담당자: 한정된 상담·지원 예산을 어느 상권에 우선 배정할지
- 상권 컨설팅 담당자: 업종 위험을 어디까지 믿고 상담할지
- 예비 창업자: 단순한 업종 순위 대신 어떤 조건을 비교해야 할지

서울시 상권분석서비스에는 업종별 점포 개업·폐업 정보가 있다. 이 분석은 **한 분기 동안 개업보다 폐업이 많으면 다음 분기 '순감소'로 표시**하는 방식이 위험도를 잘 보여주는지 점검했다.

한식은 골목상권에서 점포가 많은 업종이다(원본 집계에서 평균 **21.3개**). 점포가 많은 칸에서는 개업과 폐업 같은 사건도 발생할 기회가 많다. 이 때문에 순감소가 더 자주 관찰된다고 해서 개별 점포의 폐업 위험이 반드시 높다고 할 수는 없다.

### 분석 질문

**H2.** 골목상권의 한식과 다른 외식업을 비교할 때, 점포 규모와 유동인구를 비슷하게 맞추면 순감소 위험 격차가 줄어드는가?

**보조질문 2.** 매출, 유동인구, 점포 밀도 등의 특성 중 무엇이 다음 분기 순감소와 관련되는가?

추가로, 업종을 순위로 나열하는 방식보다 **상권 × 업종 단위의 위험도 예측**이 실제 지원 대상 선정에 도움이 될지 살펴봤다.

## 3. 데이터와 분석 단위

### 3-1. 데이터 출처·기간

서울 열린데이터광장의 서울시 상권분석서비스 데이터 가운데 점포, 추정매출, 영역, 길단위 유동인구, 집객시설 관련 테이블을 결합했다. **2023Q1~2026Q1, 총 13개 분기(다음 분기 라벨이 있는 분기는 12개)**, 외식업 **10개 업종**을 대상으로 했다. 공식 상권변화지표는 이후 외부 기준선과 후보 변수 검토에 별도로 사용했다.

이 프로젝트에서 **'칸'**은 `상권 × 업종 × 분기` 조합 하나를 뜻한다. 예컨대 어느 골목상권의 2025년 3분기 한식음식점 관측치가 한 칸이다. 개별 매장 단위 기록은 아니다.

| 데이터 처리 단계 | 행 수 |
|---|---:|
| 원본 점포 자료(전체 업종) | **995,377** |
| 외식업 10종 × 13개 분기 | **160,352** |
| 다음 분기 라벨 생성 가능 | **147,138** |
| 점포 5개 이상 | **67,495** |
| 최종 분석 표본 | **67,475** |

최종 표본에서 다음 분기 순감소 양성 비율은 **25.5%**였다. H2의 매칭은 그중 **골목상권**으로 대상을 좁혔다.

### 3-2. 점포 5개 미만을 제외한 이유

점포수가 2개 이하인 칸은 사업자 보호를 위해 매출이 비식별 처리되어 있었다. 전체 데이터의 매출 결측률 **45.4%**는 점포 5개 이상으로 제한하면 **7.1%**로 낮아졌다. 작은 칸에서는 점포 한두 곳의 개폐업만으로 순감소 비율이 크게 출렁인다는 문제도 있었다.

그래서 점포수 하한을 5개로 정했다. 그 대신 표본이 절반 이상 줄어든다. **분석 결론은 점포 5개 이상인 칸에만 적용할 수 있다.** 가장 작은 상권에 대해 별도의 분석이 필요한 이유다.

### 3-3. 연도별 `점포_수` 컬럼의 의미가 달랐다

전처리에서 가장 크게 수정한 부분이다. 2023·2024년의 `점포_수`는 전체 점포 수가 아니라 **비프랜차이즈 점포 수**를 나타냈다. 이후 파일에서는 해당 의미가 `일반_점포_수`로 바뀌었고, 총 점포 수는 별도 컬럼으로 나타났다.

이를 다음 항등식으로 확인했다.

```text
구버전 전체 점포 수 = 점포_수 + 프랜차이즈_점포_수
                    = 유사_업종_점포_수
검증 일치율 = 1.0000
```

컬럼을 올바르게 맞추자 분석 표본이 **55,795 → 67,475행(+20.9%)**으로 바뀌었다. 특히 치킨전문점은 **+390%**, 한식음식점은 **+2%**로 증가폭이 달랐다. 이 오류를 두고 업종 비교를 했다면 프랜차이즈 비율이 높은 업종에 불리한 집계가 됐을 것이다.

### 3-4. 매출은 왜 PSM 공변량에서 제외했나

매출 결측이 모든 업종에 똑같이 나타난 것은 아니었다. 매칭에 매출을 넣으면 매출이 없는 칸이 통째로 빠지고, 그 과정에서 업종마다 다른 방식으로 대조군이 줄어든다.

따라서 H2의 주 매칭 공변량은 **점포 수·유동인구·영역 면적·집객시설 수**로 두었다. 매출은 보조질문 회귀에서 결측 표시와 함께 사용하거나 민감도 확인에 한정했다.

### 3-5. 상권 전체 규모는 업종 필터 전에 계산

외식업 10종만 남긴 뒤 상권 총점포수를 구하면 실제 상권의 전체 크기를 측정하지 못한다. 그래서 전체 점포 수와 외식 점포 수는 필터 적용 전에 계산했다.

자치구 단위 보조파일 5종은 같은 구 안에서 상권을 구별할 값이 없어 매칭 공변량으로 사용하지 않았다.

### 3-6. 다음 분기 라벨과 누수 방지

타깃 `y(t)`는 다음 분기에 그 상권·업종 칸에서 `개업 < 폐업`인 경우 1, 아니면 0이다. `(상권, 업종)`별 분기 순서가 연속될 때만 `shift(-1)`로 다음 분기 정보를 연결했다. 분기 누락으로 다음 관측이 실제 다음 분기가 아닌 **140건**은 라벨을 만들지 않았다.

| 데이터 용도 | 피처 시점 | 타깃 시점 | 라벨 |
|---|---|---|---|
| 학습 | 2023Q1~2025Q3 | 2023Q2~2025Q4 | 있음 |
| 검증 | **2025Q4** | **2026Q1** | 있음 |
| 최종 예측 | **2026Q1** | **2026Q2** | 미래 결과라 없음 |

피처 시점이 2025Q4인 행을 학습에 포함하면 다음 분기인 2026Q1의 결과를 모델 선택 전에 보게 된다. 그래서 검증 분기는 학습에서 제외했다. 예측 시에도 학습과 같은 피처 생성 함수(`config.build_features()`)를 사용해 컬럼 정의가 어긋나지 않도록 했다.

## 4. 발견과 검증

### 4-0. 검정에 앞서 분포부터 확인

다음 분기 순감소 라벨 `y`는 0 또는 1이다. 이진 라벨에 Shapiro–Wilk 정규성 검정을 바로 수행하는 것은 적절하지 않다. 업종·상권 간 수준 차이를 비교할 때는 각 `상권 × 업종` 칸의 **12분기 순감소 비율**로 단위를 바꾸었다.

6분기 미만으로 관측된 칸은 비율이 불안정할 수 있어 제외했다. 그 결과 **5,687칸**을 사용했고 **735칸**이 제외됐다. 연속적인 비율 변수의 평균은 **0.249**, 중앙값 **0.250**, 왜도 **+0.592**였으며, 12분기 동안 순감소가 한 번도 없던 칸은 **7.1%**였다.

| 비교 기준 | 그룹 수 | Shapiro–Wilk 정규성 위배 | Levene p | 등분산성 |
|---|---:|---|---:|---|
| 상권 유형 | 4 | 4/4 | `< 0.0001` | 위배 |
| 업종 | 10 | 10/10 | `< 0.0001` | 위배 |
| 자치구 | 25 | 25/25 | `0.0727` | 기각되지 않음 |

비율 분포가 한쪽으로 치우쳐 있었기 때문에 **Kruskal–Wallis**를 주요 그룹 비교에 사용했다. 이 검정은 관측값을 순위로 바꾸어 비교하므로 정규분포 가정에 덜 민감하다. Levene 검정은 그룹 간 분산 차이를 확인하기 위해 함께 사용했다.

### 4-A. 한식이 1위라는 사실은 얼마나 안정적인가

단순 순감소 비율은 한식 **25.3%**, 다른 외식업 **22.9%**였다. 그런데 10개 업종 중 가장 높은 업종을 **데이터를 보고 선택**했다는 점이 중요했다. 10개 중 진짜 차이가 없는 경우라도 '1위'를 고르면 우연히 평균보다 높게 나온다.

그래서 순감소 라벨을 무작위로 섞고 각 업종의 표본 수는 유지한 채, 1위와 전체 평균의 차이를 **1,000회** 반복 계산했다.

| 비교 | 결과 |
|---|---:|
| 실제 1위(한식) − 전체 평균 | **+1.70%p** |
| 귀무상태에서 '1위 선택'이 만드는 평균 격차 | **+1.49%p** |
| 귀무상태 95% 범위 | **[+0.53, +2.94]%p** |
| 순열검정 | **p = 0.344** |
| 한식 대 나머지 척도의 선택 효과 추산 | **+2.10%p** |
| 단순 격차에서 선택 효과를 뺀 잔여 | **+0.29%p** |

관측된 1위 업종의 격차(+1.70%p) 중 약 **88%**(+1.49%p)가 최고 업종을 고르는 과정에서 생길 수 있는 격차 규모였다. 이는 '한식은 정말 더 위험하다'는 주장에 통계적 근거가 부족하다는 뜻이다.

점포수 구간만 나눠도 전체 평균과 다른 양상이 나타났다. 매칭 **전** 규모별 단순 비교에서는 각 구간 내 한식 순감소율이 더 낮았고 평균 격차는 약 **−5.3%p**였다. 다만 각 구간 안에서도 양쪽 업종의 다른 조건이 다를 수 있으므로 이후 매칭 쌍별 분석을 따로 했다. 이 단계의 층별 단순 비교와 매칭 후 층별 ATT를 섞어서 해석하면 안 된다.

### 4-B. 비슷한 칸끼리 짝지어 비교하면?

한식 칸을 처리군, 다른 외식업 칸을 대조군으로 두고 다음 공변량을 맞췄다.

- 점포 수의 로그
- 유동인구의 로그
- 상권 영역 면적의 로그
- 집객시설 수의 로그

성향점수매칭(PSM)에서는 비교 가능한 **공통지지 영역**을 확인하고, 일정 거리(캘리퍼) 이내의 칸을 1:1로 연결했다. 매칭의 품질은 표준화 평균차(SMD)로 확인했다.

- 점포수 SMD: **1.00 → 0.044** (약 95.6% 축소)
- 4개 주요 공변량 모두 `|SMD| < 0.1`
- 매칭된 쌍: **7,043쌍**
- 처리군 매칭률: **70.7%**

| 분석 방식 | 격차 | 추가 검증 |
|---|---:|---|
| 매칭 전 단순 비교 | **+2.4%p** | 매칭 전 단순 격차, 한식 대 나머지 9개 업종 |
| **PSM 평균 ATT** | **−5.57%p** | 95% CI **[−7.08, −4.17]**, McNemar `p = 2.9×10⁻¹⁴` |
| 이중강건 보정 | **−6.00%p** | 매칭·회귀 보정 병행 |
| 반사실 시뮬레이션 | **−6.01%p** | 4개 공변량을 동일하게 놓고 비교 |
| 대안 라벨(다음 분기 폐업률) | **−8.71%p** | 순감소 대신 폐업률로 재비교 |

매칭 캘리퍼, 복원추출, 난수 시드 등 **9개 설정**을 바꿔도 ATT는 대략 **−5.8~−4.1%p**에 있었다. 평균의 부호가 한 설정에서만 발생한 것은 아니었다.

![순감소율 격차 추정치: 단순 비교 +2.38%p, 성향점수매칭 −5.57, 이중강건 −6.00, 반사실 시뮬레이션 −6.01, 대안 라벨 −8.71.](images/gap-reversal.png)

이중강건 방식은 성향점수 모델과 결과 회귀의 가정 아래에서 일관성을 보완하려는 추정법이다. 두 수치가 비슷하다는 점은 반가운 결과지만 **관찰되지 않은 교란이 없다는 증명은 아니다.**

#### 매칭된 전체에 대해서만 말할 수 있다

한식 처리군의 약 **29.3%**, 특히 규모가 큰 칸은 적절한 짝을 찾지 못했다. 따라서 **−5.57%p는 매칭 가능한 한식 칸들의 평균 격차**다. 모든 한식 상권에 일반화할 수 없다.

#### 평균 ATT가 규모별로 같을까? 아니다

매칭된 7,043쌍을 점포 수 5분위로 나눴다.

| 규모 구간 | 쌍 수 | 평균 점포 | 한식 순감소율 | 대조군 순감소율 | 층별 격차(ATT) | 95% CI | 오즈비 |
|---|---:|---:|---:|---:|---:|---|---:|
| Q1 | 1,409 | 5.9 | 12.7% | 26.3% | **−13.6%p** | [−16.3, −10.5] | 0.41 |
| Q2 | 1,408 | 8.7 | 16.0% | 26.3% | **−10.3%p** | [−13.4, −7.3] | 0.53 |
| Q3 | 1,409 | 12.8 | 22.3% | 27.2% | **−4.9%p** | [−8.0, −1.5] | 0.77 |
| Q4 | 1,408 | 19.6 | 28.1% | 29.0% | **−0.9%p** | [−4.1, +2.6] | 0.96 |
| Q5 | 1,409 | 38.5 | 36.3% | 34.4% | **+1.8%p** | [−1.4, +5.1] | 1.08 |

- Woolf 동질성 검정: `Q = 79.786`, `df = 4`, `p < 0.0001`

층별 오즈비가 같다는 가정이 기각됐다. **작은 3개 구간에서는 한식의 순감소율이 뚜렷하게 낮다(신뢰구간이 0을 포함하지 않음). 점포가 20개 안팎인 Q4부터는 구간이 0을 포함하고, 가장 큰 Q5의 점추정은 +1.8%p이며 구간은 −1.4~+5.1%p다.**

![점포 수 5분위별 ATT(%p)와 95% 구간: −13.6, −10.3, −4.9, −0.9, +1.8. 작은 3개 구간은 구간이 0 아래이고 나머지 2개 구간은 0을 포함한다.](images/strata-att.png)

따라서 전체 평균만 보여주면 실제로 방향이 반대인 구간을 가릴 수 있다. 이 층별 값은 *실제 매칭 쌍을 나누어* 계산한 것으로, 점포 수를 임의로 바꿔보는 아래 반사실 곡선과는 다른 결과다.

### 4-C. 무엇이 부호 역전에 가장 많이 기여했나

추정 모형에서 공변량을 하나씩 같게 놓았을 때 한식과 타 업종의 예측 격차를 비교했다.

| 같게 놓은 조건 | 예측 격차 |
|---|---:|
| 아무것도 보정하지 않음 | **+3.06%p** |
| **점포 규모만** | **−5.84%p** |
| 유동인구만 | +3.53%p |
| 면적만 | +3.20%p |
| 점포당 매출만 | +6.30%p |
| 규모 + 유동인구 | −5.48%p |
| 4개 주요 조건 | **−6.01%p** |

관측된 평균 역전의 대부분은 **점포 규모를 맞추면서** 발생했다. 유동인구만 통제해서는 같은 결과가 나오지 않았다. 이 비교는 특정 모델 아래 계산한 반사실 예측이다. 실제 점포수를 강제로 바꾸는 정책의 효과를 측정한 것은 아니다.

### 4-D. 보조질문 2: 순감소와 관련 있는 변수

상권별 반복관측 상관을 고려한 클러스터 로버스트 표준오차를 사용해 회귀를 수행했다(`n = 67,475`). 회귀계수 자체보다는 평균 한계효과(AME)를 비교했다.

| 변수 | AME | p-value | 해석 |
|---|---:|---:|---|
| `log_점포수` | **+14.28%p** | `2.8×10⁻¹⁶⁴` | 강한 관련성 |
| `외식_비중` | **−13.84%p** | `5.2×10⁻⁶` | 음의 관련성 |
| `log_면적` | −1.39%p | 0.032 | 비교적 작은 값 |
| `log_집객시설` | −1.24%p | 0.0097 | 비교적 작은 값 |
| `log_유동인구` | +0.72%p | 0.078 | 5% 기준에서 유의하지 않음 |

여기서 `log_점포수`의 +14.28%p는 **점포 수가 e배(약 2.72배)** 증가하는 것에 대응하는 모형상의 평균 한계효과다. 점포가 하나 늘어날 때마다 14%p 위험이 증가한다는 뜻은 아니다.

또한 `p = 0.078`은 유동인구 효과가 정확히 0이라는 증거가 아니다. 이번 모형과 표본에서는 5% 기준으로 통계적으로 구분할 수 없었다는 의미다.

#### 유동인구가 순감소에서는 약하게 나타난 이유

개업과 폐업은 모두 유동인구가 많을 때 함께 높아질 수 있다. 두 사건의 **차이만** 보면 공통으로 증가하는 부분이 사라진다. 이를 확인하려고 개업 건수와 폐업 건수를 각각 음이항 회귀로 분석했고, `log(점포수)`를 오프셋으로 사용해 규모를 반영했다.

| 변수 | 개업 계수 | 폐업 계수 |
|---|---:|---:|
| `log_유동인구` | **+0.098** (`p = 7.0×10⁻⁵`) | **+0.053** (`p = 0.0095`) |
| `log_점포수` | −0.099 (`p = 1.5×10⁻⁵`) | +0.065 (`p = 0.0010`) |
| `외식_비중` | +0.472 (`p = 0.0015`) | −0.484 (`p = 1.3×10⁻⁴`) |

개업·폐업의 과분산 비는 각각 **1.81, 1.65**로 포아송의 등분산 가정보다 큰 편이어서 음이항 접근을 선택했다. 유동인구 계수는 개업과 폐업에서 같은 양의 방향이었다. 순감소만 보면 관련성이 약해지는 이유로 해석할 수 있다.

추가로 **상권 × 업종 칸 고정효과**를 적용해 같은 칸의 시간 변화만 사용했을 때 유동인구 관련성은 개업 `p = 0.865`, 폐업 `p = 0.963`으로 확인되지 않았다. 이 결과는 횡단면에서 보이는 유동인구와 점포 변동의 관련성이, 상권마다 고정되어 있는 입지 특성과 얽혀 있을 수 있음을 시사한다. 그러나 이런 검정만으로 유동인구에 인과효과가 *전혀 없다*고 확정할 수는 없다.

### 4-E. 순감소라는 라벨 자체가 규모에 유리한가

점포 수가 많은 칸은 어느 방향이든 개업·폐업 사건이 한 번이라도 발생할 확률이 높다. 그래서 사건 발생과 사건 발생 후 순감소 여부를 분리했다.

| 점포 수 | 칸 수 | 다음 분기 개업/폐업 사건 발생 | 전체 순감소율 | 사건 있는 칸에서의 순감소율 |
|---|---:|---:|---:|---:|
| 5개 | 5,487 | 29.1% | 14.6% | 50.1% |
| 8~10개 | 6,295 | 45.4% | 21.3% | 47.0% |
| 16~25개 | 4,262 | 73.9% | 31.9% | 43.2% |
| 51개 이상 | 825 | 97.9% | 37.7% | 38.5% |

규모가 클수록 전체 순감소 비율은 높았지만, 이는 **아무 사건도 발생하지 않아 0이 된 작은 칸**이 많다는 점과 관련된다. 표본의 **43.7%**는 개업·폐업 사건이 없는 칸이었다.

```text
P(순감소) = P(개업 또는 폐업 사건 발생)
            × P(순감소 | 사건 발생)
```

순감소는 사건 발생의 부분집합이므로 이 관계는 정확한 확률 분해다. 실측으로도 사건이 없는 **15,451칸**에서 순감소 라벨이 1인 경우는 없었다.

| 로지스틱 단계 | `log_점포수` 계수(조건 보정, 클러스터 SE) | 표본 수 |
|---|---:|---:|
| 사건이 발생했는가 | **+1.483**, `p < 0.001` | 31,875 |
| 사건이 발생한 경우 순감소인가 | +0.046, `p = 0.114` | 16,424 |

규모의 강한 신호는 대부분 **'사건이 한 번이라도 발생했는가'**에서 나왔다. 사건이 발생한 칸만 보면 보정 후 규모 계수는 유의하지 않았다. 따라서 '큰 상권이 오히려 안전하다'보다 **'큰 상권은 개폐업 사건이 더 많이 일어나기 때문에 순감소로 관측될 기회가 많다'**가 적절한 해석이다.

### 4-F. 입지에 민감한 정도도 업종마다 달랐다

각 업종에서 상권유형별 순감소 비율 분포가 얼마나 다른지 Kruskal–Wallis 검정과 효과 크기 **ε²**로 확인했다. 업종 10개를 반복 비교했으므로 Bonferroni 기준 `α = 0.005`를 적용했다.

| 업종 | n | H | p-value | ε² |
|---|---:|---:|---:|---:|
| 호프-간이주점 | 709 | 86.9 | `< 0.0001` | **0.1202** |
| 커피-음료 | 1,006 | 67.4 | `< 0.0001` | **0.0652** |
| 한식음식점 | 1,306 | 81.0 | `< 0.0001` | **0.0607** |
| 양식음식점 | 352 | 18.8 | 0.0001 | 0.0483 |
| 분식전문점 | 637 | 32.5 | `< 0.0001` | 0.0481 |
| 일식음식점 | 307 | 15.6 | 0.0004 | 0.0448 |
| 제과점 | 347 | 12.9 | 0.0015 | 0.0318 |
| 중식음식점 | 302 | 11.0 | 0.0041 | 0.0300 |
| 패스트푸드점 | 322 | 7.1 | 0.0281 | 0.0161 |
| 치킨전문점 | 341 | 2.1 | 0.3552 | **0.0002** |

10개 중 **8개 업종**이 보정 후에도 통계적으로 유의했다. 호프-간이주점의 효과 크기는 0.1202로 상대적으로 컸고 치킨전문점은 0.0002로 아주 작았다.

그렇다고 치킨전문점의 매출이나 폐업 위험이 '입지와 무관하다'고 단정할 수는 없다. 여기서 측정한 것은 **사용한 상권유형 분류에 따른 순감소 비율 차이**다. 배달 매출 비중 등 다른 입지·업태 변수를 분석한 것은 아니다.

### 4-G. 다음 분기 순감소·폐업 예측 성능

예측을 만들었다는 것만으로 활용할 만한 도구가 되지는 않는다. 이번에는 점포수만 사용하는 단순 규칙, 업종 과거 평균, 추가 변수를 사용한 모델을 비교하고 **시간 순서에 따른 롤링 검증**도 수행했다.

| 예측 대상/검증 | 지표 | 결과 | 비교 기준 |
|---|---|---:|---|
| 순감소 분기별 롤링 6회 | AUC 평균 | **0.666 ± 0.011** | 주요 보고 성능 |
| 순감소(칸 단위, 검증 분기) | AUC | **0.669** | 무작위 0.5, 업종평균 0.554 |
| 순감소(칸 단위) | PR-AUC | **0.418** | 양성률 기준 0.260 |
| 순감소(칸 단위) | Brier score | **0.179** | 낮을수록 확률 오차가 작음 |
| 폐업 건수(칸 단위, 검증 분기) | AUC(폐업 1건 이상 여부) | **0.711** | 점포수 단독 0.705 |
| 폐업 건수(칸 단위, 검증 분기) | 포아송 이탈도 | **0.992** | 점포수 단독 1.002 |
| 폐업 건수(칸 단위, 검증 분기) | 상위 10% Lift | **2.25배** | 하위 10% 0.44배, 점포수 규칙 2.18배 / 0.54배 |

**AUC 0.669**은 임의로 뽑은 순감소 칸과 비순감소 칸 한 쌍에서 순감소 칸에 더 높은 점수를 줄 가능성을 뜻한다. 무작위보다 낫지만 개별 칸을 높은 정확도로 맞히는 수준은 아니다. **PR-AUC 0.418**도 양성률 0.260보다 높지만, 예측 목적을 고려해 보조적으로 읽어야 한다.

**Brier score**는 예측 확률과 실제 0/1 라벨 사이의 오차를 계산하므로 순위뿐 아니라 확률값이 얼마나 맞는지도 살필 수 있다. **포아송 이탈도**는 건수 예측에 사용하는 손실 측정으로, 이번 비교에서는 0.992이 1.002보다 작아 개선이 있었지만 폭은 작았다. Lift는 예측 폐업 건수 상위(하위) 10% 칸 중 폐업이 1건 이상 있었던 칸의 비율을 전체 칸의 비율로 나눈 값이며, 점포수 규칙은 동점 칸의 순서를 200번 무작위로 바꾼 평균이다.

#### 검증 분기와 롤링 성능을 구분한 이유

검증용 2025Q4 피처 → 2026Q1 타깃 자료를 보면서 모델을 선택했기 때문에 그 검증 점수는 다소 낙관적일 수 있다. 따라서 프로젝트의 대표 성능으로는 학습 종료 분기를 움직여 평가한 **롤링 6개 분기의 AUC 0.666 ± 0.011**을 사용했다.

롤링 검증은 단일 분기에 점수를 맞춘 위험을 줄여주지만, **완전히 별도로 보관한 최종 홀드아웃**을 대체하지는 못한다. 그 부분은 한계로 남겼다.

### 4-H. 서울시 공식 상권변화지표와 비교

자체적으로 만든 규칙과 비교하는 것만으로는 실무 기준을 평가하기 어렵다. 그래서 서울시 상권분석서비스가 제공하는 **상권변화지표(HH, HL, LH, LL)**를 외부 기준선으로 사용했다.

여기서 'HL'은 상권축소로 해석되는 지표다. 이 그룹이 다음 분기 순감소를 얼마나 잘 선별하는지 확인했다.

| 변화지표 | 칸 수 | 실제 다음 분기 순감소율 | Lift |
|---|---:|---:|---:|
| **HL** | 974 | 24.3% | **0.937** |
| HH | 1,452 | 23.3% | 0.899 |
| LH | 790 | 22.9% | 0.882 |
| LL | 2,263 | 29.4% | **1.133** |

해당 평가 표본과 목표를 기준으로 하면 HL의 Lift는 1 미만이었다. **상권축소 지표 하나만으로 다음 분기 순감소를 선별하는 방법은 이 검증에서 효과적이지 않았다.** 이것이 서울시 지표의 모든 목적이나 활용이 무의미하다는 뜻은 아니다. 원래 설계 목적과 여기서 사용한 예측 목표가 다를 수 있다.

이 상권변화지표는 폐업 정보를 사용해 만들어지므로 모델의 입력 피처로 바로 넣으면 타깃 정보가 섞일 위험이 있다. 따라서 **기준선 비교 용도로만 사용**했다.

같은 파일의 `운영_영업_개월_평균`은 별도로 조사했다.

- 단일 변수 AUC: **0.538**
- `log_점포수`와의 상관: **−0.085**
- 변수 5분위별 순감소율: **29.9% → 22.2%**로 감소

신호가 강하지는 않았지만 규모만 대신 설명하는 변수도 아닌 것으로 보여 후속 피처 후보로 기록했다. **이번 최종 모형에는 포함하지 않았다.**

### 4-I. 전체 AUC보다 실제 지원할 상위 K칸 성능

자치구 담당자가 모든 상권을 지원할 수는 없다. 예산이나 인력에 따라 상위 50곳, 100곳처럼 **일부 칸만 선택**해야 한다. 따라서 전체 순위 AUC와 별도로 상위 K칸의 정밀도를 확인했다.

비교 대상은 **'점포 수가 많은 순서대로 위험하다고 판단'하는 단순 규칙**이었다.

| 선정 칸 수 K | 모델 정밀도 | 점포수 규칙 정밀도 | 모델 Lift | 두 목록 교집합 비율 |
|---|---:|---:|---:|---:|
| **50** | **0.780** | 0.380 | **3.00** | **4%** |
| 100 | 0.640 | 0.460 | 2.46 | 17% |
| 200 | 0.545 | 0.520 | 2.10 | 31% |
| 500 | 0.490 | 0.467 | 1.89 | 56% |
| 2,000 | 0.396 | 0.384 | 1.52 | 85% |

가장 적은 **50칸**만 고르면 모델이 지목한 칸의 78%에서 실제 이벤트가 관찰된 반면, 점포수 기준은 38%였다. 선정 명단도 **4%만 겹쳤다.** 모델이 단순히 점포가 많은 곳을 똑같이 고른 것은 아니라는 뜻이다.

K를 크게 늘리면 두 규칙의 결과가 가까워진다. K = 200에서는 격차가 이미 작고(0.545 대 0.520), K = 2,000에서는 0.396 대 0.384이다. 이 프로젝트에서 모델의 가치가 특히 크다고 볼 수 있는 부분은 **아주 제한된 수의 지원 대상을 선별하는 상황**이었다.

![상위 K칸 정밀도: 모델과 점포수 규칙, 양성률 26.0% 기준선. K = 50에서 모델 0.780 대 규칙 0.380이고 K = 200에서는 격차가 작다(0.545 대 0.520).](images/operating-point.png)

#### 점포 규모를 비슷하게 맞춘 뒤에도 유리한가

전체에서 점포수와 위험이 모두 커지는 구조라면, 큰 상권만 고르는 규칙도 높은 성능을 보일 수 있다. 점포수 5분위 안에서 따로 비교했다.

| 규모 구간 | 평균 점포수 | 실제 양성률(기저율) | 모델 Lift | 점포수 규칙 Lift (동점 무작위 평균, 95% 범위) |
|---|---:|---:|---:|---:|
| Q1 | 5.3 | 15.0% | **1.548** | 1.02 (0.73–1.34) |
| Q2 | 7.3 | 18.4% | **1.450** | 1.18 (0.99–1.37) |
| Q3 | 11.0 | 21.9% | **1.483** | 1.19 (1.10–1.27) |
| Q4 | 18.8 | 30.8% | **1.247** | 1.16 (1.13–1.18) |
| Q5 | 64.5 | 43.7% | **1.166** | 1.08 (1.07–1.08) |

규모별 다섯 구간 모두에서 모델 Lift가 점포수 규칙의 95% 범위를 웃돌았다. 평균 격차는 작은 3개 구간에서 0.53, 0.27, 0.29였지만 큰 2개 구간은 약 0.09였다. 특히 Q1에서는 **1.55 대 1.02 (0.73–1.34)**이었고 가장 큰 Q5에서는 1.17 대 1.08였다. 이 비교는 검증 한 분기 기준이며 모델 Lift 자체의 표본 오차는 포함하지 않는다. 전체 폐업 건수 모델 AUC는 점포수만 쓴 베이스라인 **0.705 → 0.711**, 즉 **+0.006**에 그쳤다. 하지만 선택 범위가 작은 운영 상황에서는 차이가 더 컸다.

![점포 수 5분위 안의 Lift: 모델 1.55, 1.45, 1.48, 1.25, 1.17, 점포수 규칙 1.02, 1.18, 1.19, 1.16, 1.08(동점 무작위 평균, 2.5~97.5% 범위). 무작위 선택은 1.0.](images/size-strata-lift.png)

단, 선정 칸 수와 양성 사건 종류가 다른 여러 지표를 섞으면 해석하기 어렵다. **순감소 이진 예측 AUC(0.669), 폐업 건수 예측 기준의 AUC(0.711), 상위 K칸 정밀도(0.780)**는 서로 다른 평가 설정에서 나온 결과다.

#### 업종 순위상관은 성능 근거에서 제외

초기에는 업종별 예측 순위상관이 높아 보이는 결과(**0.915**)가 있었다. 그러나 점포수만 사용한 모델에서도 똑같은 결과가 나와, 업종별 정답 순위 자체가 안정적인지 확인했다.

- 반분(split-half) 순위상관: **+0.110**
- Spearman–Brown 보정 신뢰도: **0.198**
- 반복 분할 상관 5~95% 범위: **−0.36 ~ +0.54**
- 신뢰도 제곱근 기준 참고 상한: **√0.198 ≈ 0.444**
- 프로젝트 모델의 업종 순위상관: **0.515**

순위 목표 자체의 변동이 크기 때문에 **0.515를 안정적인 업종 예측 성능으로 제시하지 않았다.** 신뢰도 상한은 단순한 가정에 의존하는 참고 계산이므로 엄밀한 보편적 성능 상한처럼 해석하지 않는다.

자치구 × 업종처럼 더 잘게 집계한 한 분기 순위의 반분 신뢰도는 **0.035**, 자치구 단위는 **0.086**으로 낮았다. **6개 분기를 합쳐** 재면 각각 **0.259**, **0.537**으로 나아졌지만 한 분기 순위표를 신뢰하기에는 부족하다.

## 5. 이 결과를 어떻게 이해했나

### 5-1. 순감소는 폐업 확률과 다른 지표다

개업과 폐업 건수의 차이를 이진화하면, 개폐업 사건이 드문 작은 칸이 순감소 0으로 많이 기록된다. 따라서 순감소율로만 업종 위험을 정하면 점포 규모가 뒤섞인다. 이번 표본에서 한식의 순감소율이 높게 나온 것도 **한식 업종 칸의 규모가 큰 점**과 밀접하게 연결되어 있었다.

이를 근거로 순감소 지표를 없애야 한다고 결론내리지는 않았다. **'점포 수 대비 폐업률'과 함께 보여주어 서로 다른 질문에 답하도록 하는 것**이 더 실용적이다.

### 5-2. 유동인구는 '안전함'의 단순한 대리변수가 아니다

유동인구가 많을수록 개업과 폐업 건수가 모두 높은 방향으로 나타났지만, 같은 칸 안에서의 시간 변화에서는 유의한 관련성이 확인되지 않았다. 즉 **사람이 많다는 사실만으로 개별 점포의 생존 가능성이 높다고 판단하기 어렵다.** 다만 유동인구에 인과효과가 전혀 없다고 말할 근거도 없다.

### 5-3. 평균 한식 효과가 아닌 업종 × 규모 조합을 봐야 한다

매칭 후 전체 평균 ATT는 −5.57%p였지만 점포수 Q1부터 Q5까지의 차이는 −13.6%p에서 +1.8%p까지 변했고, 큰 2개 구간은 신뢰구간이 0을 포함한다. '한식은 무조건 안전'이나 '한식은 무조건 위험' 같은 한 문장으로 정리하면 중요한 조건을 놓친다.

### 5-4. 업종별로 상권유형과의 관련성이 달랐다

호프·간이주점, 커피·음료, 한식은 상권유형별 분포 차이가 비교적 컸고 치킨전문점은 작았다. **업종별로 입지와 관련된 분석이 얼마나 유용한지 다를 수 있다**는 단서다. 반대로 이를 근거로 특정 지원정책의 효과를 예상할 수는 없다.

### 5-5. 작은 상권 안에서 추가 위험 신호를 찾는 모델의 용도

폐업 건수 기반 전체 AUC는 점포수만으로도 상당 부분 설명됐지만, 규모를 비슷하게 묶어 보면 모델이 추가적인 구분력을 보였다. 지원 대상 상위 K칸 선정처럼 명확한 운영 상황에서 비교하는 것이 실제 활용에 더 가깝다.

## 6. 운영에 적용한다면

### 제안 1. 업종 평균 순위보다 칸별 위험점수로 지원 대상 선정

| 항목 | 제안 |
|---|---|
| 대상 | 자치구 소상공인 지원·컨설팅 배정 담당 |
| 실행 | `forecast_2026Q2_cell.csv`의 칸별 예측을 활용해 예산이 허용하는 상위 K칸을 후보로 선정 |
| 근거 | 상위 50칸 정밀도 **0.780**, 점포수 규칙 **0.380**; 목록 겹침 4% |
| 운영 시점 | 관련 분기 데이터 공개 후 재산출. 기존 2026Q2 예측 명단 2,737칸은 과거 산출물 |
| 성과 검증 | 실제 지원 이후 유사 위험점수의 미지원 칸과 비교해 효과를 별도 추정 |

이 모델은 **위험 후보를 찾는 도구**이지 지원사업을 하면 위험이 얼마나 줄어드는지를 알려주는 모델이 아니다. 실제 배정에는 사업자의 신청 의사, 지원 가능성, 점포 정보 등도 필요하다.

### 제안 2. 유동인구를 상담에서 설명할 때 개업·폐업을 함께 보여주기

| 항목 | 제안 |
|---|---|
| 대상 | 창업 상담센터, 상권 컨설턴트 |
| 실행 | 유동인구가 많다는 사실을 '매출 기회'와 '사업체 회전'의 두 관점에서 설명 |
| 근거 | 음이항 분석에서 유동인구 계수 개업 +0.098 / 폐업 +0.053 |
| 검증 | 상담 내용 변경 전후의 의사결정·생존 결과를 장기간 추적 |

관찰자료에서 나타난 양의 연관성을 개별 점포의 실제 폐업 확률 증가로 직접 옮기지는 않아야 한다.

### 제안 3. 대시보드에 순감소율과 점포수 대비 폐업률 병기

| 항목 | 제안 |
|---|---|
| 대상 | 서울시 상권분석 서비스 운영자 |
| 실행 | 업종별 순감소율 옆에 규모 보정 관점의 폐업률을 함께 표시 |
| 근거 | 예측 업종별 두 지표 순위상관 **−0.370**; 한식 순감소 1위, 폐업률 10위(꼴찌) |
| 검증 | 이용자가 업종별 위험 설명을 오해하는 빈도가 줄어드는지 확인 |

기존의 공식 상권변화지표도 '다음 분기 순감소 예측'이라는 특정 목표로 평가하면 HL Lift가 0.937이었으므로, 지표 용도를 분명하게 설명할 필요가 있다.

### 제안 4. 업종의 입지 민감도에 따라 상담 주제를 다르게 하기

| 구분 | 관련 업종 예 | 제안 방향 |
|---|---|---|
| 상권유형과 차이가 비교적 큰 업종 (`ε² ≥ 0.06`) | 호프·간이주점, 커피·음료, 한식 | 입지·상권 특성부터 상담 |
| 차이가 작게 나타난 업종 (`ε² < 0.02`) | 치킨전문점, 패스트푸드점 | 입지뿐 아니라 원가, 배달 플랫폼, 프랜차이즈 계약 조건 등의 추가 변수 조사 |

이 구분은 상담의 조사 우선순위를 제안하는 정도다. 특정 지원 수단을 적용했을 때 실제 폐업률이 낮아지는지는 아직 검증하지 않았다.

| 층별 이질성 | Woolf `p < 0.0001`이므로 평균 ATT 하나를 업종 전체 특성처럼 사용하기 어려움 (작은 구간은 뚜렷한 음수, 큰 구간은 0과 구분되지 않음) |
| 입지 효과 검정의 표본 | 업종별 `n = 302~1,306`; 적은 업종의 추정은 상대적으로 불안정 |
| 집계자료 | 개별 점포의 폐업 시점·업력·경영 상황을 알 수 없음 |
| 인과해석 | 관측된 공변량만 맞췄으므로 임대료·자본금·사업주 특성 같은 미관측 교란 가능 |
| `영역_면적` 정의 | 면적이 정확히 무엇을 뜻하는지 문서상 확정되지 않아 해석에 주의 필요 |
| 신뢰구간 | 부트스트랩은 표본 변동을 다루지만 모형 지정 오류까지 모두 반영하지 않음 |
| 별도 최종 홀드아웃 부재 | 검증 분기로 모델을 선택했으므로 독립적인 최종 테스트가 필요 |
| 집계 순위 신뢰도 | 한 분기 자치구/자치구×업종 순위는 반분 신뢰도가 낮아 보고 지표로 부적절 |
| 예측 성능 | 폐업 건수 AUC **0.711** 중 점포수 단독 규칙도 **0.705**; 운영상 이점은 상위 K 선정에서 더 명확 |

### 다음에 확보하고 싶은 데이터

1. **개별 사업체의 개업·폐업 이력.** 지금은 칸 단위 사건 수만 알 수 있다. 사업체 연령과 운영 기간이 있으면 생존분석(Cox 등)으로 어떤 시점에 위험이 높아지는지 볼 수 있다.
2. **상권별 임대료.** 점포수가 많은 칸에서 왜 개폐업이 많이 일어나는지 해석하려면 비용 구조를 확인해야 한다. 자치구 단위 임대료만으로는 상권 내 차이를 구분하기 어렵다.
3. **`운영_영업_개월_평균`.** 이번에는 단변량 AUC 0.538만 확인하고 최종 모델에 넣지 않았다. 점포수와 상관이 거의 없어 후속 피처 후보로 의미가 있다.
4. **배달 플랫폼 의존도와 업태 정보.** 상권유형만으로 구분하기 어려운 업종별 경영 특성을 설명할 수 있다.
5. **지원정책 도입 시점과 대상 정보.** 지금 분석은 위험을 찾는 것이지 지원 효과를 식별하지 않는다. 정책 시행 자료가 있으면 DID나 이벤트 스터디 같은 준실험 접근을 검토할 수 있다.

### 8-5. 용어 설명

| 용어 | 이 프로젝트에서의 의미 |
|---|---|
| **칸** | 상권 × 업종 × 분기 하나. 개인 점포는 아니다. |
| **순감소** | 다음 분기에 개업보다 폐업이 많아진 경우 |
| **처리군 / 대조군** | 한식음식점 칸 / 조건이 비슷한 다른 업종 칸 |
| **공변량** | 매칭에서 비슷하게 맞출 점포수, 유동인구, 면적, 집객시설 |
| **공통지지** | 한식과 타 업종의 성향점수가 서로 겹쳐 비교 가능한 구간 |
| **캘리퍼** | 성향점수 차이가 너무 큰 쌍을 제외하는 최대 거리(표준편차 0.2배) |
| **SMD** | 매칭 전후 공변량 균형을 비교하는 표준화 평균차 |
| **ATT** | 매칭 가능한 처리군과 대조군 간 평균 결과 격차(여기서는 인과 주장에 주의) |
| **AME** | 설명변수가 변할 때 모형 예측 확률의 평균 변화 |
| **Woolf 검정** | 규모 층별 오즈비가 같은지 확인하는 동질성 검정 |
| **ε²** | Kruskal–Wallis에서 그룹 분포 차이의 크기를 요약하는 효과크기 |
| **Lift** | 특정 선정 그룹의 실제 발생률 / 전체 기준 발생률 |
| **정밀도** | 위험하다고 선정한 칸 중 실제 이벤트가 나타난 비율 |
| **누수** | 예측 시점에 알 수 없는 미래 정보가 학습·피처에 들어가는 문제 |
| **train/serve skew** | 학습과 실제 채점에서 변수 계산이 달라지는 문제 |
| **롤링 검증** | 시간 순서에 따라 학습 종료 시점을 움직이며 반복 평가 |
| **홀드아웃** | 모델 선택에 쓰지 않고 마지막에 한 번만 성능을 확인할 자료 |

**최종 정리:** 이 프로젝트에서 배운 것은 '한식이 위험하다/안전하다'라는 업종 순위보다, **순감소라는 지표의 성격·점포 규모·상권 조건·예측의 사용 목적**을 함께 봐야 한다는 점이다. 통계적으로 확인한 격차와 실제 정책 개입의 인과효과는 별도로 구분해야 한다.
